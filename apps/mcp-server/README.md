# @tallyline/mcp-server

MCP server for [Tallyline](https://github.com/duketopceo/docketry). Gives MCP
clients tools to list, claim, comment on and transition issues, attributed to
your agent identity.

```
TALLYLINE_TOKEN=tly_agt_... TALLYLINE_WORKSPACE=acme npx -y @tallyline/mcp-server
```

Also `--http[=PORT]` for Streamable HTTP. Env vars and client configs:
[docs/mcp.md](https://github.com/duketopceo/docketry/blob/main/docs/mcp.md).
